# 📽️ MovieMatch

MovieMatch, kullanıcıların **film önerileri almasını** ve favori filmlerine göre eşleşmeler yapmasını sağlayan bir Flutter projesidir.

---

## 🚀 Özellikler

- 🎬 Film öneri sistemi  
- 📱 Flutter ile **Android / iOS** desteği  
- 🔗 Firebase fonksiyonları ve backend bağlantısı  
- 📊 Kullanıcı bazlı tercih algoritmaları *(gelecekte)*

---

## 🧩 Gereksinimler

Projeyi çalıştırmak için:

- Flutter SDK (>=3.0)  
- Android Studio / Xcode  
- Firebase proje yapılandırması  
- Bir Android/iOS cihaz veya emulator

---

## 📦 Kurulum

1. Reposu klonlayın:

```bash
git clone https://github.com/cinaratac/moviematch.git
```

2. `kapalibeta1.0` branch’ine geç:

```bash
git checkout kapalibeta1.0
```

3. Gerekli paketleri yükle:

```bash
flutter pub get
```

---

## 🔧 Firebase Ayarları

1. Firebase’e yeni proje oluşturun  
2. Android & iOS yapılandırmasını ekleyin  
3. `google-services.json` ve `GoogleService-Info.plist` dosyalarını ilgili klasörlere koyun  
4. Firebase Authentication / Firestore aktif edin

---

## ▶️ Çalıştırma

```bash
flutter run
```

---

## 📌 Proje Yapısı

| Klasör | Açıklama |
|------|---------|
| /android | Android yapı dosyaları |
| /ios | iOS yapı dosyaları |
| /lib | Uygulama kodu |
| /web | Web desteği |
| /assets | Resimler & ikonlar |
| /functions | Firebase fonksiyonları |
